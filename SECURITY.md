# Security · Beveiliging

**English.** Found a security problem in one of these plugins? Please report it privately through the contact form at <https://koekoek.ai/#contact> (mention "security" and the plugin name). Do not open a public issue for security problems. We aim to reply within 2 working days.

**Nederlands.** Een beveiligingsprobleem gevonden in een van deze plugins? Meld het via het contactformulier op <https://koekoek.ai/#contact> (noem "beveiliging" en de naam van de plugin), niet in een openbaar issue. We reageren binnen 2 werkdagen.

Scope: the code in this repository. Nest-privacy runs fully on your own computer and sends nothing to Koekoek or anyone else.
